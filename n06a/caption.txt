Anthropic just handed Agent Skills to the Agentic AI Foundation, part of the Linux Foundation. A skill is one folder with a SKILL.md file that teaches an AI agent one task. Anthropic says more than 70 agent platforms already use them, including ChatGPT, Cursor, GitHub Copilot and VS Code, with nearly 280 million installs by its own count. It now sits next to MCP as a neutral standard. Sources: Anthropic, Linux Foundation. One shared skill standard: good for builders, or too shaped by one company?
